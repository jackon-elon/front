# FORM & FLOW · 交互实验室

用 React + TypeScript 构建的交互式 3D 展览。白色首页中的蓝色、铬金属与玻璃雕塑，随滚动拆开层次，再进入深色展厅和可调整的实验空间。

## 本地运行

需要 Node.js 22.12 或更高版本。

    npm ci
    npm run dev

打开 http://127.0.0.1:5173/ 。停止服务用 Ctrl+C。

    npm test
    npm run build
    npm run preview

构建产物在 dist/，可以放在普通静态网站服务器中。使用 HashRouter，页面地址如 /#/works，无须服务器配置路由重写。当前仓库提供源代码和 CI，不包含生产部署配置。

## 可以体验什么

- 四段滚动体验：进入 → 解构 → 探索 → 改变。
- 实时程序化 Three.js 雕塑、GPU 粒子、金属液滴、螺旋光帆；移动鼠标改变视角。
- 作品搜索、收藏筛选、独立实验页、颜色/密度/速度调整、暂停和重置。
- 保存命名实验、恢复参数；浏览器 localStorage 持久保存。
- 用户主动开启的合成环境音、画质设置、减少动态效果、键盘可操作弹窗。
- 手机与桌面布局、WebGL 不可用时的降级浏览。

目前没有账号、云同步或后端。收藏属于当前浏览器与当前网站地址；清除浏览器数据会清除收藏。主雕塑解构通过曲面层位移完成，粒子是独立实验；不是物理流体模拟。

## 想让 AI 准确修改

开发预览默认开启左下角“区域定位”。移动鼠标显示中文区域名、组件路径、CSS 选择器和当前生效的字号；Alt+点击固定，或点“固定当前”，再用“复制定位”把区域描述粘贴给 AI。Alt+L 开关。正式构建默认关闭，左下角仍可主动开启；选择仅记住当前浏览器会话。

3D 对象会定位到模型与场景文件。GPU 粒子使用体积范围命中，蓝框为对象投影包围范围。说明集中在 src/learning/，不在每块页面内容上添加额外标记。

先看 [页面与代码定位指南](docs/PROJECT_MAP.md)。它把屏幕上的每个区域对应到组件、样式和 3D 逻辑，并给出可以直接对 AI 说的修改示例。

## 技术与素材

- React 19：组件、状态和页面交互。
- TypeScript：约束数据与组件接口。
- Three.js：程序化曲面、材质、环境光与粒子着色器。
- GSAP ScrollTrigger：将滚动进度映射到场景变化。
- React Router：静态网站中的页面切换。
- Vite / Vitest：开发构建与状态逻辑测试。

几何、图标和环境音由代码生成，未使用外部 3D 模型。Manrope 字体来自 Google Fonts；无法访问时自动使用系统字体。视觉参考 [Lusion](https://lusion.co/)、[Active Theory](https://v5.activetheory.net/) 的空间感与滚动叙事，未复制其源代码或素材。
