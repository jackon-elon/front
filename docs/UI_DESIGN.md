# AgentLens UI design

这是以真实 Agent 工作记录为内容的 React 交互作品。首页负责视觉探索与可操作的会话展览，检索、对比和连接页面负责深入操作。各页面共用快照、对比集合和详情入口。

## 参考与设计取舍

实际浏览了 [Lusion](https://lusion.co/) 和 [Basement Studio](https://basement.studio/)。借鉴前者的大画面与少量清晰操作，以及后者由完整场景建立视觉主角的方式。页面构图、唱片图形、组件和交互代码独立实现，没有复制参考站的素材或源代码。

视觉选择暖纸色、近黑与朱红，采用大字海报和唱片展览构图。数据图形与实际会话对应，让用户在视觉场景内进行选择与回放。

## 视觉系统

- 首屏近黑底，标题桌面约 10.3vw（76–172px），中间一行描边；朱红唱片与纸白字构成主画面。正文 19px，主要按钮 17px。
- 展册纸色底，章节标题桌面 58–120px；卡片标题 24px、回放标题 44–78px。编号等次要信息 12–14px。
- 手机重新编排：海报标题 18vw，唱片移到标题下方，展册标题 56px，回放标题 43px。正文 15–16px。
- 顶部固定导航替代侧栏；全屏菜单使用大字号朱红版面。全局模式始终明确区分本机实时、虚构演示与导入记录。
- `src/experience.css` 负责视觉探索与全局外壳；`src/styles.css` 保留深入工作区组件样式。移除了旧外壳和侧栏的 109 条废弃 CSS 规则。

## 体验顺序

1. `/` 信号场景：唱片的轮廓由按时间排列的请求 Token 生成。长会话压缩为最多 64 桶，保留全部用量和原始请求范围。点击扇区定位该桶的第一条请求，下方滑块可逐条精确定位。
2. 会话展册：朱红前景唱片与偏转的背景唱片。拖动超过阈值、方向键或按钮切换；展开时横向排列并保持选中卡片在中央。Agent、标题与项目筛选同时改变唱片、总量和回放内容。实时数据变动保持所选 session ID。
3. 请求拆解：输入、输出和缓存读取的柱图；播放、暂停与 range 滑块控制原始请求序号。缓存读取属于输入，未额外计入 Token 总量。未知字段保持未知。
4. 深入操作：进入虚拟列表、详情、三槽对比或 `/workspace` 实时统计。工作区仍有时间桶下钻、面板宽度调整、历史图表、暂停快照与真实增量通知。

## 动效与可访问性

- 首屏在固定场景中横向移动文字、旋转请求唱片；无循环伪活动。鼠标移动只产生轻微倾斜。
- 展册切换、叠放与展开使用 Motion spring。只渲染少量可见唱片，所有会话仍可通过检索和前后切换访问。
- 首屏点击通过 SVG inverse screen matrix 还原倾斜、旋转后的局部坐标。分桶和角度映射有独立测试。
- 页面转场使用遮幅和透明度；全屏菜单从上方揭开。菜单、详情与命令面板使用 Portal、焦点约束、Escape 和焦点恢复。
- 系统 reduced-motion 和应用动画开关关闭首屏滚动变换及指针倾斜；核心功能保留。手机采用自然单列场景。
- 全局 Ctrl / Cmd K；展册左右方向键；回放滑块支持原生键盘操作。开发模式 F8 可以复制区域名称、组件、CSS 选择器与字号。

## 数据与展示

本地首页默认读取本机快照，通过 SSE 更新。在线站点明确展示虚构演示数据；不会上传本机日志。没有数据时显示空状态，连接失败保留重试与数据源入口。

验证以真实浏览器的桌面与 390px 手机页面为准。视觉效果不能替代筛选、回放、详情与对比的操作验收。
