# UI 设计与公开资料

日期：2026-10-10。

## 视觉结构

参考 [苹果 MacBook Pro 产品页](https://www.apple.com.cn/macbook-pro/) 的实际页面：先给产品主视觉，再横向浏览亮点，再点击了解具体能力。产品画面、字号和节奏比堆叠动画更重要。

本站统一黑色与石墨灰的视觉系统，导航、首屏、影像云、影像智能、协作及详情采用同一套文字和边界颜色。银灰大标题与蓝色行动入口在首屏居中，下方由 React 绘制产品预览，而非放大一张带界面文字的图片。主标题桌面约 66–78px，手机约 39–48px；正文采用 17–21px。

首屏有影像阅览、报告空间与协作路径三种预览，复用可访问 Tabs 与合成图集。影像帧状态在预览切换后保留，上一帧和下一帧按边界禁用；三个面板拥有相同的最小高度，减少切换跳动。产品外框用细边缘、高光和受控阴影表达材质。新阅片协作照片仅使用一次，展示尺寸小于原图，旧终端图与医生照片归档，不继续进入部署。

亮点使用原生横向滚动与 scroll-snap，支持左右按钮和键盘。桌面卡片采用左侧文案、右侧图形的构图，宽度为视口的 84%，上限 1480px。四项分别展示机构连接、资料分享、报告复核与远程协作，不复用首屏或医生照片。手机将文案放在图形上方。初始滚动为 0，第一张从统一边距开始。

参考苹果功能图库的呈现方式，每个选项对应不同的主画面：区域网络、手机与纸质报告、共享阅片与协作；六帧质控、报告编辑、双视图对照。切换不只更换说明文字，操作与布局都随用途变化。产品细节使用 220ms 淡入，减少动态设置下即时显示。首页所有产品章节均处于正常文档流，没有长时间固定的扫描动画。

## 内容依据

- [影联网](https://www.imagingunion.com/iunet/login)：平台标注安徽讯飞影联科技有限公司，提供检查报告、远程会诊入口及公开联系方式。
- [港交所公开法律意见书](https://www.hkexnews.hk/listedco/listconews/sehk/2024/1218/11480774/2024121800093_c.pdf)：历史软件登记包括医学影像存储传输、影联网门户、电子胶片、影像质控与远程会诊。用来确认业务方向，不代表当前版本、临床性能或产品承诺。
- [数坤官方站](https://cn.careverse.com/)：2026-06-04 公开讯飞影联合作动态，涉及区域影像云与医学影像 AI。
- [科大讯飞 2024 年度报告](https://static.cninfo.com.cn/finalpage/2025-04-22/1223191180.PDF)：集团医疗业务描述智能医学影像助手、质控、报告草稿与多期对比，为交互场景提供灵感。这些方向不能直接当成讯飞影联已发布产品的完整规格。

因此：首页采用区域影像云、数字影像（电子胶片）、远程会诊和医学影像 AI 的产品方向。质控、报告、多期对比的具体界面标注为场景概念；医疗 Agent 仍为协作交互概念。未使用未核实的机构数量、资质、准确率或临床成果。

## 交互与排版约束

- 点击直接改变产品场景，文字与界面共用一份配置；各个子场景保留自己的本页操作状态。
- 卡片边界会禁用方向按钮；触控与键盘均保留原生滚动体验。
- 通用弹窗管理焦点、Escape 和滚动锁定；详情代码按需加载。
- 手机将影像与资料栏纵向排列；菜单折叠不压缩主标题。
- 动效遵守系统减少动态设置，?motion=off 提供可复现的静态展示。
- 使用合成关节影像，不接入实际病例；终端图是软件展示用的通用设备，不代表公司制造这些硬件。
