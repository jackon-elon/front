# AgentLens UI design

产品是一个本地 Agent 使用观测台。核心流程为「了解总体投入 → 找到具体会话 → 检查请求结构 → 并排对比 → 连接或导入数据」。主导航按照这四个任务组织，不出现教程或技术名词占据业务界面。

## 视觉系统

- 浅色纸面与深墨色文字，靛蓝表示操作；首页的深蓝调用主舞台用淡蓝表示输入、黄绿色表示输出。Codex 绿、Claude 铜、WorkBuddy 靛蓝，来源颜色在所有图表一致。
- 首页主视图由真实请求时间桶绘制 SVG；没有随机生成粒子、背景流线或宣传横幅。
- 系统字体避免依赖外部字体服务；桌面大标题 40–56px，正文 17–18px、主要数字 38–60px、卡片标题 18–22px、导航 17px、表格标题 17px。12–14px 只用于编号、时间和次要说明。
- 主间距 24px、主面板圆角 18px、会话卡片圆角 12–14px。以浅底、深色主图、白色交互卡片建立清楚主次，避免所有内容挤成相同的小方框。
- 日期、项目、数据源筛选放在总览顶部。演示 / 本地 / 导入模式始终在全局栏明确展示。

## 页面结构与状态

总览：连接状态和检查时间、Agent / 工作区筛选、深色调用曲线与会话牌组、四个指标、历史曲线、最近请求。曲线由真实时间桶总量构造，时间柱和历史日期下钻到会话。会话默认叠放视图，前后切换最近六个会话；前景卡片显示来源、用量、缓存及最近请求轨迹，切换采用弹簧位移和轻微转角，也可切换为可展开列表。最新数据更新时保持已选 session ID。中间分隔条可拖动，键盘左右键也可调整，Home 恢复默认。手机隐藏分隔条改为单列。

会话探索：搜索与筛选、保存视图、虚拟表格、浮动对比托盘。列标题负责排序；复选槽负责对比；会话标题打开详情。空搜索结果提供清除筛选。

会话透镜：侧栏保留探索现场；请求趋势、虚拟明细列表、单次请求口径、独立的标签备注表单。Focus trap、Escape 关闭与焦点恢复支持键盘操作。

对比工作台：最多三张可排序卡片，配共同请求序号上的上下文曲线与指标对照。不同长度的会话保留曲线空缺，缺少上限的比例数据不补零。

数据源：显示各适配器的发现状态；导入先校验和预览再保存；连接失败保留进入演示和管理数据源的入口。

## 动效规范

- 路由内容 220ms 淡入与轻微位移，加载时保留骨架，不让整个导航闪烁。
- 卡片增减 / 排序使用 spring layout；托盘出现保持上下文。
- 详情侧栏 350ms 滑入，遮罩淡入；图表更新 550ms。
- 会话展开与收起使用高度动画；邻近卡片使用 layout 弹簧。时间柱只随真实数据变化，不生成伪活动。
- 暂停固定时间线和牌组的快照，后台连接不停止；新增计数来自 response ID 差分，初次历史加载不算新增。
- 系统 reduced-motion 与应用动画开关都应生效；静态统计仍可正常操作。

## 响应式

桌面采用固定侧栏与多列面板。950px 以下逐步减少列数，720px 以下侧栏变为抽屉、统计保留两列、图表和对比卡片纵向排列。数据表与活动图允许各自横向滚动，页面本身不横向溢出。

## 微调定位

本地开发按 F8，悬停标记区域显示组件文件、CSS 选择器和标题字号，复制描述后补充要求即可发给 AI。定位工具只在开发模式出现。

设计验收以实际页面为准：先检查总览的层级与桌面文字，再检查详情、对比、导入状态和 390px 手机视口。
