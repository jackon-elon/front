# UI 设计与公开资料

## 连续转场与交互查看器

摄影亮点通过连续的位置、标题和图片转场进入详情，关闭后返回原入口；数字影像入口默认展示数字影像场景。其他章节入口保持普通详情方式，避免缺少对应卡片时制造飞入效果。减少动画模式直接进入详情。

查看器位于云影像详情的资料浏览中，采用与官网一致的石墨灰和淡蓝操作反馈。移动与框选是明确的工具状态；缩放比例、撤销重做、清除与导出均提供真实操作。标注随原图移动，不作为固定在屏幕上的装饰框。

桌面列表与查看器并列，手机纵向排列。只在影像画布禁用原生触控滚动以支持双指；其余区域继续正常滚动。数据与标注明确属于合成示意，无医疗测量单位或诊断结论。

日期：2026-10-10。

## 视觉结构

参考 [苹果 MacBook Pro 产品页](https://www.apple.com.cn/macbook-pro/) 的主视觉、摄影图库和章节层级。当前首页以产品叙事为主，取消业务模式与医疗方案的标签栏，复杂操作保留在按需加载的详情展台。

统一黑色与石墨灰。首屏由银灰大标题、简洁入口和大型阅片终端组成，1440 × 1000 时终端完整可见；主标题约 78px。章节标题桌面最高 76px，正文 19–22px，手机标题约 35–48px、正文 18–19px。

亮点为三张独立摄影：医院建筑、数字影像手机、影像显示细节。桌面三列同时可见；中等宽度显示两列；手机逐张原生滚动。第一张从 20px 边距开始，图片原始宽 1122px，桌面展示约 411px。没有溢出时隐藏滚动按钮，有溢出时按实际偏移计算索引和边界。

云影像用阅片协作照片和同时可见的三项能力说明。AI 章节用清晰的并列影像与关联资料展示，取消首页工作区切换。Agent 章节展示协作路径，点击可进入真正的状态流程。区域医疗、医共体与医疗机构各有自己的文字段落和合作入口，页脚直接定位相应方案。

首屏终端、三张亮点封面、阅片协作照片各使用一次，避免重复官网照片。详情中的图集按阅片功能复用，它表达同一份检查资料的六个视图。摄影图均为设计示意，不代表真实机构、病例或公司制造硬件。

移除旧首屏和亮点图形组件、两份独立 CSS，清理旧首页叠加样式。首页样式由 editorial.css 统一维护；narrative.css 只留产品展台共用规则。

## 内容依据

- [影联网](https://www.imagingunion.com/iunet/login)：平台标注安徽讯飞影联科技有限公司，提供检查报告、远程会诊入口及公开联系方式。
- [港交所公开法律意见书](https://www.hkexnews.hk/listedco/listconews/sehk/2024/1218/11480774/2024121800093_c.pdf)：历史软件登记包括医学影像存储传输、影联网门户、电子胶片、影像质控与远程会诊。用来确认业务方向，不代表当前版本、临床性能或产品承诺。
- [数坤官方站](https://cn.careverse.com/)：2026-06-04 公开讯飞影联合作动态，涉及区域影像云与医学影像 AI。
- [科大讯飞 2024 年度报告](https://static.cninfo.com.cn/finalpage/2025-04-22/1223191180.PDF)：集团医疗业务描述智能医学影像助手、质控、报告草稿与多期对比，为交互场景提供灵感。这些方向不能直接当成讯飞影联已发布产品的完整规格。

因此：首页采用区域影像云、数字影像（电子胶片）、远程会诊和医学影像 AI 的产品方向。质控、报告、多期对比的具体界面标注为场景概念；医疗 Agent 仍为协作交互概念。未使用未核实的机构数量、资质、准确率或临床成果。

## 交互与排版约束

- 首页业务介绍直接可见；详情用配置驱动场景，保留各子场景的本页操作状态。
- 图库支持触控、按钮与键盘；方向按钮在实际边界禁用，ResizeObserver 处理尺寸改变。
- 通用弹窗管理焦点、Escape 与滚动锁定；详情使用 React.lazy / Suspense。
- 章节处于正常文档流，没有长时间固定的扫描动画。
- 动效遵守系统减少动态设置，?motion=off 提供静态验证入口。
- 三类方案通过原生锚点定位；手机纵向排列，不用缩小字体塞入三列。

## 资料浏览体验

高级资料操作放在影像云详情内，点击后才加载浏览器模块。首页继续用摄影和产品叙事。详情延续石墨灰底色、清晰的大标题与克制的蓝色选中反馈；桌面列表与预览并列，手机纵向展示，不压缩两列文字。

资料行使用缩略图、编号与分组，支持搜索、分组、排序、收藏和键盘定位。预览提供六帧与元数据；影像为已有合成图集，6,000 条索引只是用于模拟规模的元数据。数量标记明确说明单位与数据来源。

渲染失败显示与详情一致的文字及操作按钮，保留外层弹窗。重试和页面重载分别对应局部重新挂载与重新获取模块，不将技术报错混进产品文案。
